# لقطات المراجعة البصرية

لقطات Chromium حقيقية مقتطعة من الرسوم بعد التعديلات، بعرض نافذة 390 أو 1366 بكسل. خط Cairo من حزمة @fontsource/cairo قدم محلياً لأن Google Fonts محجوب في بيئة الاختبار. لم تُغيّر صور الكتاب أو تُخزّن في المستودع. هذه اللقطات أمثلة للمراجعة وليست بديلاً عن اختبار كافة الحالات.
