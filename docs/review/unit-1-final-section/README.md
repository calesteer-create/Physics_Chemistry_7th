# القسم الختامي للوحدة الأولى — التحقق العملي

## المشكلة
بعد دمج PR #18 ثم PR #19 كان قسم «أراجع وأختبر نفسي — الوحدة الأولى» غير ظاهر
بوضوح للطالب ضمن تسلسل محتويات الوحدة: وُضعت بطاقته بجانب بطاقة اختبار الوحدة
في شبكة ثنائية (`md:grid-cols-2`) قبل اختبار الوحدة الشامل لا بعده، دون تمييز
بصري يجعله واضحاً كنهاية لتسلسل الوحدة.

## الإصلاح
- أصبح تسلسل الوحدة الأولى: الدروس الخمسة ← بطاقة «اختبار الوحدة الأولى الشامل» ←
  بطاقة «أراجع وأختبر نفسي — الوحدة الأولى» كآخر عنصر مستقل في الصفحة.
- بطاقة المراجعة بعنوانها الصريح «أراجع وأختبر نفسي — الوحدة الأولى»، ووصف قصير
  يوضح أنه قسم مراجعة تفاعلية شاملة (٤ محطات، ٢٠ بندًا، تلميحات وحلول خطوة بخطوة)،
  مع شارة «القسم الختامي للوحدة — أسئلة الكتاب ص 63–64» وإطار مميز بلون المنصة
  الأساسي دون تغيير هويتها، ومتناسقة مع بطاقات الدروس والاختبار (أيقونة + عنوان + وصف).
- تُعرض البطاقتان مباشرةً دون الكشف التدريجي (`.reveal`): الكشف التدريجي يُبقي
  العناصر أسفل الجزء المرئي من الشاشة بشفافية صفرية إلى حين التمرير، فلا تظهر
  أبداً في لقطات التصدير الكامل أو عند تعذّر رصد التقاطع.
- لم يُمسّ محتوى قسم المراجعة ولا بنك اختبار الوحدة ولا أي درس أو دفتر طالب.
  العنوان الوحيد المتغيّر هو ترتيب وعرض `src/app/units/[slug]/page.tsx` للوحدة الأولى.

## ما تم التحقق منه عملياً (متصفح Chromium بلا رأس عبر playwright-core + @sparticuz/chromium)
- ترتيب الروابط داخل `main` في `/units/unit-1/`:
  خمسة دروس ← `/quizzes/quiz-unit-1/` ← `/units/unit-1/review/` (المراجعة أخيراً).
- النقر على بطاقة المراجعة يفتح `/units/unit-1/review/` ويعرض العنوان
  «أراجع وأختبر نفسي — الوحدة الأولى».
- المحطات الأربع (صح أم خطأ ثم صحّح / الكتلة والثقل على الكواكب / اقرأ الخط البياني /
  المسائل) ولوحة المراجعة تفتح من تبويباتها، و20 نقطة بيانية تفاعلية تقرأ
  إحداثييها عند الضغط، وتغذية راجعة التحقق تظهر بعد الإجابة، وأزرار «تحقّق من الإجابة»
  في المحطة الرابعة عددها 9.
- لا أخطاء JavaScript ولا استجابات ≥ 400 أثناء الجولات.
- العرض على 1440px و390px: كل البطاقات ظاهرة بعد التمرير (صفر عناصر `.reveal` خفية).
