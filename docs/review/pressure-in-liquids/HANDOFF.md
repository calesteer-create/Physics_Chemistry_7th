## ٤. لماذا لم يُنشأ الفرع المستقل في هذه الجلسة

قيد الجلسة يربط العمل بفرع واحد ثابت هو
`arena/63e42615-physics-chemistry-7th` ويمنع إنشاء فرع آخر أو التبديل إليه؛
أي عمل على فرع آخر لا يُربط بهذه الجلسة. لذلك **توقّفنا عند تجهيز التسليم**
وفق شرط المستخدم، ولم يُنشأ فرع ولم يُفتح PR. التثبيت وُضع في التزام واحد على
الفرع الحالي **ليكون قابلاً للنقل** (`git cherry-pick` أو `git am`) إلى الفرع
المستقل، وليس تنفيذاً للدرس منه.

## ٥. خطوات الجلسة / الفرع المستقل (تُنفَّذ لاحقاً، لا الآن)

1. افتح جلسة Arena جديدة على فرع مستقل مُنشأ من أحدث `origin/main`، أو أنشئ الفرع
   في بيئة تسمح بذلك ثم اربط الجلسة به:
   ```bash
   git fetch origin main
   git switch -c <pressure-in-liquids-branch> origin/main
   ```
2. انقل التزام الاعتماد (دون نقل أي تنفيذ للدرس):
   ```bash
   git log --all --format='%H %s' --grep='approve: pressure-in-liquids notebook'
   git cherry-pick <APPROVAL_COMMIT_SHA>
   # أو: git am docs/review/pressure-in-liquids/approval.patch
   ```
3. تحقّق من القفل قبل أي كتابة:
   ```bash
   cd docs/review/pressure-in-liquids/approved && sha256sum -c notebook.sha256
   npm run test:stage2
   ```
4. نفّذ الدرس **كاملاً في PR واحدة** (الشرح + الرسوم + المختبرات + أنشطة الكتاب +
   التدريبات + الاختبار الإلكتروني + دفتر الطالب)، بلا تقسيم، وبلا دمج.
5. عند نشر الدرس: أضف **سطر بصمة JSON واحد** للدرس الجديد في
   `tests/stage2/notebook-invariance.test.ts` دون تغيير البصمات السبع، واجعل عرض
   دفتر الطالب مطابقاً حرفياً لـ `approved/notebook.txt` (تحسين بصري فقط).
6. أرسل التقرير النهائي: رابط PR، SHA الالتزام، قائمة الملفات، عدد الرسوم/
   المختبرات/التفاعلات، بصمة الدفتر، نتائج الاختبارات، ولقطات 1440/390/320.

## ٦. القيود المنقولة كما هي (قائمة تحقق، لا شرح جديد)

- الدفتر Untouchable: لا تعديل نص/ترتيب/بند/إضافة/حذف بلا موافقة صريحة؛ تحسين
  العرض البصري فقط مع التطابق الحرفي الكامل.
- لا دافعة أرخميدس، لا طفو، لا غوص أجسام، لا قوانينها. مسألة السمكتين = فرق ضغط
  بين عمقين فقط.
- `1 atm = 101325 Pa = 760 mmHg` مع بيان أن `10135` هي القيمة المطبوعة في الكتاب
  وأن التصحيح من المنصة ولا يُنسب إلى نص الكتاب.
- `P = ρgh` لضغط السائل، `Pt = P0 + ρgh` للضغط الكلي؛ مسائل ضغط السائل تُحل
  بالأول فقط.
- `m = ρV` و`w = mg` علاقات من دروس سابقة، لا قوانين جديدة.
- الرسم البياني كما ورد، مع توضيح أن المحور الأفقي هو العمق `h` بالمتر، بلا تغيير
  صامت.
- ترقيم المراحل ١–٩ موحّد في الخطة والتوثيق والاختبارات.
- لا مساس بالدرس الأول «الضغط» ودفتره واختباره ومختبره ورسومه، ولا بنك الوحدة
  الأولى، ولا مراجعة الوحدة الأولى، ولا أي درس أو دفتر سابق.
- موقع Static على GitHub Pages، بلا خادم/API/قاعدة بيانات، تصحيح محلي، KaTeX
  معزول LTR، فحص متصفح حقيقي على 1440/390/320.

## ٧. ملاحظة بيئية محمولة

الاختبار `tests/stage2/simple-machines.test.ts`، الحالة
«legacy lesson sources … byte-identical to base»، يفشل في هذه النسخة **الضحلة**
من المستودع لأن الالتزام التاريخي `e443a051c1a0c6be0a91895087d06575c7439200`
غير موجود محلياً (`git rev-parse --is-shallow-repository` = `true`). هذا الفشل
**سابق ومستقل** عن إضافة القفل هذه، ولا يُعالَج بتعديل الاختبار المحمي؛ يُعالَج
في الجلسة الجديدة بجلب التاريخ الكامل (`git fetch --unshallow`) قبل تشغيل
الاختبارات الكاملة. بقية اختبارات `stage2` (١٢٥ من ١٢٦) و`lint` و`typecheck`
تمرّ بنجاح، واختبار القفل الجديد والاختبار المحمي يمرّان.
