# مراجعة بصرية — «أراجع وأختبر نفسي — الوحدة الأولى»

قسم مراجعة ختامي على المسار `/units/unit-1/review/`، مبنيّ من صفحتي الكتاب 63–64 فقط،
ومستقل عن اختبار الوحدة الإلكتروني (لم يُعدّل). أربع محطات وخمس لوحة مراجعة، بإجمالي 20 بندًا.

## البنية

| المحطة | المصدر | البنود |
|---|---|---|
| ١ — صح أم خطأ؟ ثم صحّح | ص 63 — السؤال الأول | 5 عبارات، كل واحدة مع ثلاثة تصحيحات وواحد صحيح |
| ٢ — الكتلة والثقل على الكواكب | ص 63 — السؤال الثاني | جدول الأجسام الأربعة + 3 أسئلة |
| ٣ — اقرأ الخط البياني | ص 63 — السؤال الثالث | 3 أشكال بيانية تفاعلية + اختيار الوصف |
| ٤ — المسائل | ص 64 — السؤال الرابع | جدول الخنفساء، تخطيط النقاط، السرعة، ثلاث ربيعات، مخطط القوى، عمل الاحتكاك، العمل الكلي |
| لوحة المراجعة | — | النتيجة، تقدّم كل محطة، الأخطاء، «أعد المحاولة»، روابط الدروس |

## كيف تُشغَّل المراجعة البصرية

```bash
npm run build
python3 -m http.server 8083 --bind 0.0.0.0 --directory <مجلد يضم out باسم Physics_Chemistry_7th>
AUDIT_URL=http://localhost:8083/Physics_Chemistry_7th npx tsx tests/visual/unit1-review-audit.ts
```
