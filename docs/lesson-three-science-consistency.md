# مراجعة الاتساق العلمي للدرس الثالث — الجولة اللاحقة

> مراجعة لاحقة للقصاصات المكبرة وتصحيح التفسير الشرطي لص39: [تقرير القصاصات](lesson-three-page39-crops.md).

المصدر صور صفحات الكتاب 29–40 المرفقة من المستخدم، ومحتوى الطالب وبنك التدريب وحلول المعلم. هذه المراجعة تُحدّث نتائج الجولة السابقة ولا تمحو جدولها التاريخي. أذن المستخدم بتصحيح حلول المعلم المخالفة للكتاب، واستثنى عطل مختبر الدرس الثاني من الإصلاح.

## الاختبارات والمعاينة

- `npm run lint` و`npm run typecheck` و`npm test` (72/72) و`npm run build` و`git diff --check` نجحت. يظهر تحذير حجم حزمة من Vite وتحذيرات مقاييس أحرف من KaTeX أثناء الاختبارات.
- `npm run test:browser:teacher` نجح بمتصفح Chromium فعلي على 390 و1366: لا حلول في DOM قبل الدخول أو بكلمة خاطئة؛ عرض حلول الدرس الثالث بعد الدخول؛ إزالة الحلول عند الخروج وبعد إعادة التحميل. **البوابة شكلية في تطبيق ثابت، وليست حماية للمصدر أو مصادقة أمنية.**
- `npm run test:browser:lessons`: ثلاث اختبارات ناجحة وواحد فاشل عند مختبر الدرس الثاني بـ `groundY is not defined`. اختبار المتصفح العام وتطبيق الإنتاج يتوقفان للسبب ذاته قبل استكمال بقية السيناريو. التحقق على نسخة main عند `fc1af8f` أعاد الخطأ نفسه؛ لم يُعدّل المختبر.
- أُعيد التقاط الرسوم باستخدام Chromium فعلي وCairo من ملفات محلية لاعتراض طلب الخط الخارجي، بعرضي 390 و1366: 31 رسم/حالة بعد التعديل لكل عرض، وفحص الحدود لم يجد عناصر خارج viewBox. روجعت بصرياً رسوم الكتاب والطاولة واليد والبندقية واللقطات المختارة لحلول المعلم؛ فحص الحدود ليس ضماناً شاملاً لعدم التداخل. لقطات حلول المعلم في `docs/review/teacher-science/`، واللقطات الكاملة في الحزمة المحلية.

## التوصية

لا تُقدَّم النسخة بوصفها مكتملة علمياً بالكامل: سؤالا صورة الكتاب والطاولة والبندقية في ص39 ما زالا بحاجة إلى توضيح مصدر السهمين والقوة الممثلة في صورة البندقية. جرى إزالة الأجوبة الخاطئة وتوضيح حدود الاستنتاج بدلاً من تخمين إجابات. كما تبقى حالة ص38 الغامضة، وخطأ مختبر الدرس الثاني السابق خارج النطاق. يُنصح بإبقاء PR مسودة إلى حين حسم الصور ومراجعة العطل في مهمة مستقلة.
