# الفيزياء الممتعة — نموذج الواجهة (المرحلة B)

واجهة عربية RTL فاتحة لمنصة الفيزياء والكيمياء للصف السابع. تضم: الصفحة الرئيسية، ومساحة الطالب، والمسار الدراسي الموحد، والدرس التجريبي بعشر محطات ينتهي بدفتر الطالب. جميع النصوص والبيانات تجريبية، ولا يوجد أي محتوى من المنهاج. لا توجد مصادقة ولا حفظ للتقدم ولا إجابات معلم.

## البنية

- `src/demo-data.js`: الرابط والمهندس (بيانات عامة فقط).
- `src/course.js`: المسار الدراسي (قائمة واحدة مرتبة)، والمحطات العشر بترتيبها، وأقسام الدفتر.
- `src/math.js`: مكونات المعادلات (KaTeX، باتجاه LTR) والكمية "العدد ثم الوحدة".
- `src/icons.js`: أيقونات خطية موحدة ورسم الصفحة الرئيسية.
- `src/main.js`: التوجيه بالروابط (`#/`، `#/student`، `#/path`، `#/lesson/demo/<محطة>`) وعرض الصفحات.
- `src/style.css`: نظام التصميم (الألوان والأزرار والبطاقات والحالات).

## قرارات تقنية

- **KaTeX** (`katex`، رخصة MIT): مكتبة خفيفة تعمل في المتصفح دون خادم، وتدعم الكسور الرأسية. تُعرض المعادلات في كتلة LTR معزولة عن النص RTL، والصيغ غير الصالحة لا تكسر الصفحة.
- **التوجيه بالروابط** بدل متغيرات الذاكرة: يبقى الطالب في مكانه عند التحديث، ويعمل زر الرجوع.
- لا توجد أي اعتماديات إضافية للمتصفح للفحص؛ يُشغَّل Chromium من خارج المستودع (انظر أدناه).

## التشغيل

```sh

npm run dev
```

يتطلب `npm run test:browser` متصفح Chromium. يُحدَّد مساره عبر `CHROMIUM_PATH`:

```sh

```
