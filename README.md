# الفيزياء الممتعة — الوحدة الأولى والدرس الأول

واجهة عربية RTL فاتحة لمنصة الفيزياء والكيمياء للصف السابع. المحتوى الحالي محصور في:

- **الوحدة الأولى: الحركة والتحريك**، ولها صفحة مستقلة.
- **الدرس الأول: الحركة والسكون**، اعتماداً على صفحات الكتاب 3–16.
- تسع مراحل تعلم مرتبة بعد نقل الاختبار إلى منطقة مستقلة، ودفتر الطالب هو الأخير.
- لا توجد بطاقات لدروس أخرى، ولا اختبار للوحدة، ولا تقسيم إلى قسمي فيزياء وكيمياء.
- اختبارات الدروس والوحدات مستقلة عن المراحل، ولا تُنشأ قبل اعتماد المحتوى.

## البنية

- `src/course.js`: تعريف الوحدة والدرس والمراحل التسع وأقسام الدفتر.
- `src/book-content.js`: محتوى الكتاب مرتباً، مع التعريفات والجداول والرسوم والتطبيق والأسئلة.
- `src/lesson-content.js`: الاكتشاف، والتوضيح الإثرائي المنفصل، والأمثلة المحلولة، والملخص والدفتر.
- `src/motion-lab.js`: مختبر الحركة والسكون؛ المرجع، وتتبع المسار، والزمن/الموضع مع جدول ورسم واستنتاجات.
- `src/assessments.js`: أسئلة الفهم والتدريب المتدرج والتغذية الراجعة التفسيرية.
- `src/diagrams.js`: رسوم SVG تعليمية قابلة لإعادة الاستخدام.
- `src/math.js`: مكونات KaTeX باتجاه LTR ومعالجة آمنة للأخطاء.
- `src/teacher-zone.js`: منطقة المعلم؛ بوابة كلمة المرور الشكلية، ثم عرض الحلول حسب الوحدة والدرس.
- `src/teacher-solutions.js`: حلول أسئلة نهاية الدروس، مفتاحها معرّف الدرس في `course.js`، ولكل درس معتمد إدخال إلزامي.
- `src/main.js`: التوجيه `#/`, `#/student`, `#/unit/motion`, `#/lesson/motion-rest/<مرحلة>`.
- `src/style.css`: نظام التصميم المتجاوب.
- `src/demo-data.js`: بيانات التواصل العامة السابقة، وليست محتوى منهاجياً.

## قرارات المحتوى

- نص الكتاب لا يُصحّح داخل قسم **محتوى الكتاب**.
- كل إضافة تظهر بعنوان **توضيح إثرائي** أو **نشاط إثرائي تفاعلي**.
- الموضع والمسافة المقطوعة مميزان بوضوح. استعمال `|x₂ − x₁|` للمسافة مشروط بحركة مستقيمة في اتجاه واحد؛ في الذهاب والعودة تجمع أطوال المسار.
- تُحفظ مصطلحات الكتاب: السرعة الوسطية، السرعة المتوسطة، السرعة اللحظية، الحركة المنتظمة، والحركة المستقيمة المنتظمة.
- لا يقدم الدفتر إجابات معلم أو ملاحظات خاصة به.

## KaTeX

المعادلات والكسور والمؤشرات والوحدات تُبنى بواسطة KaTeX محلياً، لا بصور ثابتة. اتجاه المعادلات LTR ومعزول عن RTL. المعادلات الطويلة لها تمرير داخلي عند الحاجة، ولا يظهر LaTeX خام للطالب عند الخطأ. خطوط KaTeX وملفاتها تدخل في بناء Vite للإنتاج.

```sh
npm run lint

npm test
npm run build
```

### اختبار المتصفح والمقاسات

يحتاج اختبار Playwright إلى Chromium. حدد مساره عبر `CHROMIUM_PATH`:

```sh
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

أو يمكن تثبيت حزمة متصفح محلية للفحص دون إضافتها إلى اعتماديات المشروع:

```sh
npm install --no-save --package-lock=false @sparticuz/chromium
npm run test:browser
```

يفحص الاختبار التنقل، والمراحل التسع، وتفاعلات المختبر والتدريب، واتجاه المعادلات وخطوطها، والمقاسات:

- 1366×768
- 1920×1080
- 768×1024
- 390×844

لحفظ لقطات فعلية في `artifacts/screenshots` (مجلد مستبعد من Git):

```sh
SCREENSHOTS=1 npm run test:browser
```

### اختبار نسخة الإنتاج

```sh
CHROMIUM_PATH=/path/to/chromium npm run test:browser:production
```

يبني الأمر `dist` ثم يختبرها عبر `vite preview` تحت `/Physics_Chemistry_7th/`، بما في ذلك تحميل خطوط KaTeX والملفات المحلية والتفاعلات والمقاسات.

## مناطق الاختبارات والمعلم

منطقة الاختبارات تعرض تبويباً مستقلاً لكل درس معتمد، لكن الاختبار النهائي يظل غير منشأ حتى اعتماد محتواه؛ لا تُنشأ اختبارات وحدات قبل تأكيد اكتمال الوحدة. حلول الاختبارات، وحلول نهاية الدروس ضمن منطقة المعلم، لها هياكل مستقلة حسب الدرس دون نشر حلول غير موثقة. لا توجد مصادقة حقيقية: المستودع عام وGitHub Pages موقع ثابت.

**بوابة منطقة المعلم** بوابة عرض شكلية داخل الواجهة فقط، وليست حماية أمنية. تظهر شاشة الدخول عند كل فتح للمنطقة، ولا تُرسم حلول الأسئلة في الصفحة قبل إدخال كلمة المرور الصحيحة. تُقفل المنطقة عند مغادرتها أو تحديث الصفحة، ويعيد زر «تسجيل الخروج» إلى شاشة الدخول. ملفات الحلول مدمجة في الحزمة المنشورة وتظل قابلة للقراءة من المصدر؛ هذا مقبول للبوابة الشكلية ولا يُعد حماية.

الأسئلة المتعلقة بالشكل أو بالحكم المتنازع عليه تُذكر في «ملاحظة للتحقق» داخل كل سؤال، ولا تُخفى.

تستخدم تبويبات الكتاب والمناطق الأخرى أدوار ARIA `tablist` و`tab` و`tabpanel` وتدعم أسهم الاتجاهين وHome/End.
