# الفيزياء والكيمياء — الصف السابع (منصة تعليمية تفاعلية)

منصة **موقع ثابت (Static Website)** مبنية بـ Next.js 16 (App Router) + React 19 +
TypeScript + Tailwind CSS v4، لتقديم دروس الفيزياء والكيمياء للصف السابع (المنهاج
السوري): شرح موسّع، رسومات الكتاب معاد إنتاجها، مختبرات تفاعلية، أسئلة الكتاب مع
حلولها، اختبارات إلكترونية، و«دفتر الطالب». اللغة العربية (RTL) وخط Cairo، والرموز
العلمية عبر KaTeX.

تعمل المنصة **بالكامل داخل متصفح الطالب**: لا حسابات، ولا تسجيل دخول، ولا قاعدة
بيانات، ولا API، ولا خادم. كل التفاعلات (المراحل، المختبرات، الاختبارات، أسئلة
الكتاب) تُنفَّذ في المتصفح.

- **الرابط:** <https://calesteer-create.github.io/Physics_Chemistry_7th/>
- **النشر:** GitHub Actions ← GitHub Pages (تفاصيل في [`DEPLOY.md`](./DEPLOY.md))

## المتطلبات

- Node.js 22+ (لا حاجة لأي قاعدة بيانات أو متغيّرات بيئة)

## الأوامر

| الأمر | الاستخدام |
|---|---|
| `npm run dev` | تشغيل بيئة التطوير محليًا |
| `npm run build` | بناء الموقع الثابت إلى مجلد `out/` |
| `npm run lint` | تدقيق الشيفرة (ESLint) |
| `npm run typecheck` | فحص الأنواع (TypeScript) |
| `npm test` | اختبارات الوحدة (node:test) |

`npm run build` ينتج مجلد `out/` كاملاً بملفات HTML/CSS/JS فقط — وهو ما يُنشر على
GitHub Pages كما هو.

## بنية المشروع

- `src/content/` — المحتوى التعليمي (الوحدات، الدروس، بنك الاختبارات).
- `src/components/lesson/` — عرض الدرس: الكتل، أسئلة الكتاب، دفتر الطالب.
- `src/components/lab/` — المختبرات التفاعلية.
- `src/components/figures/` — الرسومات العلمية (SVG).
- `src/components/math/` — KaTeX العادي + KaTeX داخل SVG.
- `src/lib/quiz-grading.ts` — تصحيح منطقي نقي (يعمل في المتصفح).
- `tests/stage2/` — اختبارات الوحدة (سلامة بنك الاختبارات، التصحيح، تطبيع الإجابات).

## الاختبارات الإلكترونية

البنك الكامل (أسئلة + إجابات معتمدة + شروح) موجود في `src/content/quiz-bank.ts`.
في نسخة الموقع الثابت تُرسل الأسئلة فقط إلى المتصفح، والتحقق من اكتمال الإجابات
يجري في المتصفح قبل عرض شاشة «تم التسليم» — دون درجة ودون كشف لصحة الإجابات أو
للحلول، تمامًا كما كان سلوك النسخة السابقة.
