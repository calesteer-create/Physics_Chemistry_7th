# الفيزياء الممتعة — نموذج المرحلة الأولى

نموذج واجهة عربي باتجاه RTL لمنصة الفيزياء والكيمياء للصف السابع. يحتوي على صفحة ترحيب ومساحة طالب ودرس تجريبي بسبع محطات ينتهي بدفتر الطالب. جميع بيانات الطالب والتقدم ونصوص الدرس تجريبية وليست محتوى من المنهاج. لا توجد مصادقة أو إجابات معلّم.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```sh
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية. يستخدم المشروع Vite وJavaScript دون إطار واجهات؛ بيانات النموذج منفصلة في `src/demo-data.js`، والأنماط والمكونات في `src/style.css` و`src/main.js`. الخطوط تُحمّل من Google Fonts مع بدائل محلية عند عدم توفرها.

## التحقق

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

فحص typecheck هنا فحص توافق JavaScript من TypeScript وليس ضماناً لتغطية أنواع صارمة. لا يتم حفظ التفاعلات أو التقدم؛ النموذج لا يتصل بخادم أو قاعدة بيانات. الخطوة التالية بعد مراجعة التصميم هي اعتماد المحتوى والمنهاج وتصميم نموذج البيانات وإضافة اختبارات واجهة قبل بناء الوظائف الفعلية.

### اختبار المتصفح

يتطلب `npm run test:browser` متصفح Chromium مثبتاً ومكتبات النظام الخاصة به؛ يستخدم `/usr/bin/chromium` افتراضياً، أو يمكن تحديد مساره:

```sh
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

يشغّل الاختبار خادم Vite مؤقتاً على المنفذ 4175 ويفحص التنقل والمحطات والدفتر والتفاعل، واتجاه الصفحة، والتجاوز الأفقي على مقاسات سطح المكتب واللوحي والهاتف. لا يغني هذا الاختبار عن مراجعة بصرية يدوية أو اختبارات المتصفحات الأخرى.
